# La Maison Verte – Arreau

Site officiel de réservation de la location saisonnière **La Maison Verte** à Arreau.

Version de référence : **v1.0.0**  
Date : **27/06/2026**  
Statut : **Stable / version fonctionnelle sauvegardable**

---

## Objet du projet

Le site permet de présenter la maison, de gérer les demandes de réservation en direct, les paiements, les clients, les calendriers et l'administration de la location.

Il ne s'agit plus seulement d'un site vitrine : le projet comprend désormais une véritable interface de gestion.

---

## Technologies principales

- React
- Vite
- Supabase
- Stripe
- Netlify
- Resend
- Synchronisation calendriers ICS Airbnb / Booking
